غذای‌تان را با صدا سفارش بدهید

آماده است. میکروفون شما فقط در هنگام تماس روشن می‌شود.

مثلاً بگویید: «دو قابلی پلو و یک دوغ می‌خواهم.»

این تماس برای ثبت درست سفارش ضبط می‌شود. اگر دستیار متوجه نشود، یک کارمند به شما زنگ می‌زند.
